# ranobelib-epub-userscript

Юзерскрипты для скачивания ранобэ с [ranobelib.me](https://ranobelib.me): одной книгой в **EPUB** или архивом **ZIP** с HTML/TXT-главами.

Оба скрипта пишут файл на диск потоком, поэтому большие тайтлы на тысячи глав скачиваются без ошибки *out of memory*.

> [!WARNING]
> **Только для личного использования, не распространяйте скачанные файлы.**
> Тексты и переводы принадлежат их авторам, переводчикам и правообладателям.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (или Violentmonkey).
2. Откройте ссылку нужного скрипта — менеджер сам предложит установку:

| Скрипт | Что делает | Установить |
|---|---|---|
| EPUB | Одна книга с оглавлением и картинками | [ranobelib-epub.user.js](https://raw.githubusercontent.com/QRANG/ranobelib-epub-userscript/main/ranobelib-epub.user.js) |
| ZIP | Архив: HTML-читалка + TXT + картинки | [ranobelib-zip.user.js](https://raw.githubusercontent.com/QRANG/ranobelib-epub-userscript/main/ranobelib-zip.user.js) |

Скрипты обновляются автоматически через Tampermonkey.

## Использование

Откройте страницу тайтла на ranobelib.me. В правом нижнем углу появятся кнопки:

- **📖** — скачать EPUB
- **📥** — скачать ZIP

В Chrome и Edge откроется окно «Сохранить как», после чего файл пишется прямо на диск. На кнопке отображается прогресс в процентах. В Firefox файл собирается в браузере и скачивается в конце.

EPUB получает имя по названию тайтла: `84179--sabikui-bisconovel` → `Sabikui bisco.epub`.

## EPUB

- **Оглавление в два уровня:** Том → Глава. Работает в любой читалке — в файле есть и `nav.xhtml` (EPUB 3), и `toc.ncx` (EPUB 2 для e-ink и старых приложений).
- **Нумерация** глав с ведущими нулями, у каждого тома своя титульная страница.
- **Картинки** встроены в книгу; обложка отображается в библиотеке читалки.
- **Страница «Описание»**: авторы, жанры, переводчики, аннотация.
- Разметка глав приводится к валидному XHTML.

## Настройки

В начале каждого скрипта есть блок `CONFIG`:

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `compression_level` | `9` | Сжатие текста, `0`–`9`. `0` — быстрее, но файл больше |
| `chapters_per_pause` | `100` | Через сколько глав делать паузу, чтобы не упереться в лимит запросов |
| `pause_ms` | `60000` | Длительность паузы |
| `legacy_line_breaks` | `false` | *(EPUB)* Включите, если текст глав слипается в сплошные абзацы |

## Известные ограничения

- Скачивание долгое: сайт ограничивает частоту запросов, поэтому скрипт делает паузы.
- Если название тайтла само заканчивается словом «novel», оно пропадёт из имени файла.
- Картинки в WebP/AVIF могут не отображаться в старых читалках.
